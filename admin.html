IMSA • GITHUB PAGES

Admin backend tidak dijalankan di GitHub Pages.

Versi GitHub Pages ini dibuat statis agar Dashboard, CSS, Mode Presentasi, foto kegiatan, dan QR dapat tampil langsung dari repository. GitHub Pages tidak menjalankan Python/Flask, SQLite, session login, upload, atau route /admin.

Untuk mengubah isi website:

Edit source Flask asli di komputer melalui admin lokal, lalu buat ulang versi statis; atau ubah file website dan upload kembali ke GitHub. Folder flask_source_backup di paket ini menyimpan source admin Flask asli.
